# Windows ICS Fixer (AutoIt)

Автоматический скрипт для решения проблемы с «засыпанием» и постоянными сбоями общего доступа к интернету (Internet Connection Sharing / ICS) в ОС Windows 7, 8, 10 и 11.

---

## 📌 Описание проблемы

В инфраструктуре розничной торговли или распределённых точек (ТТ, островки в торговых центрах) часто используется схема подключения оборудования, где:
1. Ноутбук/нетбук получает интернет по **Wi-Fi** от внешней точки доступа (например, MikroTik).
2. К **Ethernet-порту** этого же ноутбука подключено стороннее оборудование (РРО / кассовый аппарат / POS-терминал).
3. На ноутбуке настроен сетевой мост / общий доступ (ICS) с Wi-Fi на Ethernet.

### В чём заключается баг Windows:
Служба общего доступа Windows (`SharedAccess` / `ICS`) имеет критическую уязвимость на уровне архитектуры:
* После перезагрузки системы, смены Wi-Fi сети или переподключения интерфейса служба формально остается в статусе `Running`, но **фактически перестает транслировать IP-пакеты** на Ethernet-адаптер.
* На практике это приводит к ежедневному отвалу кассового оборудования каждое утро, требуя ручного сброса галочки «Разрешить другим пользователям сети использовать подключение к интернету» в свойствах адаптера.

---

## 💡 Решение

Данный скрипт, написанный на **AutoIt**, полностью автоматизирует процесс восстановления и поддержания работоспособности ICS через системный COM-API Windows (`HNetCfg.HNetShare`), исключая необходимость человеческого вмешательства.

Скрипт был успешно развернут через доменные политики (GPO) на **130+ торговых точках**, полностью ликвидировав повторные обращения в службу технической поддержки.

---

## ⚙️ Как это работает (Технические детали)

1. **Активация служб и фикс реестра:**
   * Автоматически переводит службы `SharedAccess` и `RemoteAccess` в режим автозапуска и стартует их.
   * Прописывает в реестр параметр `EnableRebootPersistConnection = 1` по пути `HKLM\SOFTWARE\Microsoft\Windows\CurrentVersion\SharedAccess`, гарантируя сохранение конфигурации ICS после перезагрузки ОС.
   * Включает IP-маршрутизацию (`IPEnableRouter = 1`).

2. **Динамическое определение адаптеров:**
   * Скрипт проверяет наличие активного Wi-Fi соединения (SSID) с помощью `netsh wlan show interfaces`.
   * Через регулярные выражения (RegEx) и парсинг вывода `netsh interface ip show config` автоматически забирает точные системные имена беспроводного (`Wi-Fi / Беспроводная сеть`) и проводного (`Ethernet`) адаптеров. 
   * Поддерживает кириллические названия интерфейсов благодаря OEM2ANSI декодированию.

3. **Сброс и реанимация ICS через COM API:**
   * Использует стандартный COM-объект `HNetCfg.HNetShare.1` (`INetSharingConfigurationForINetConnection`).
   * Выполняет мягкий «Reset» шеринга: полностью отключает расшаривание на найденной паре адаптеров, выдерживает паузу в 7 секунд и заново инициализирует связку **Public** (Wi-Fi) и **Private** (Ethernet) интерфейсов.

## 🚀 Требования и запуск

### Требования:
* **ОС:** Windows 7 / 8 / 8.1 / 10 / 11.
* **Права:** Требуются права Администратора (`#RequireAdmin`).
* **Зависимости AutoIt:** Включает библиотеки `Constants.au3` и `encoding.au3`.

### Компиляция и запуск:
1. Откройте `.au3` файл в **SciTE / AutoIt3**.
2. Скомпилируйте скрипт в `.exe` файл (x86/x64).
3. Настройте запуск `.exe` файла при входе пользователя в систему или через **Планировщик задач Windows** (Task Scheduler) при загрузке системы / подсоединении к Wi-Fi сети.

---

### ⚠️ Важное примечание по локализации (Важно!)

В коде скрипта используется жесткий поиск беспроводного адаптера по его языковому имени в Windows. Перед компиляцией проверьте название вашего Wi-Fi адаптера в системе (команда netsh interface ip show config) и укажите его ключевое слово в скрипте вместо WAN:

```autoit
If StringInStr($str1[$u],'"') And StringInStr($str1[$u],'WAN') Then
```
